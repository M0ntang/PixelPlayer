## 🌟 Отличия форка от оригинального PixelPlayer

Этот форк создан с упором на эстетику **Flat Design**, максимальную плавность рендеринга (60/120 FPS без микрофризов) и удобство повседневного прослушивания:

### 🎨 1. Полностью плоский дизайн (Flat & Clean Design)
* **Удалены все искусственные тени и elevation:** экраны, нижние шторки (Bottom Sheets), карточки треков, диалоги и панели больше не перегружены многослойными тенями.
* **Чистый визуальный стиль:** акцент на типографике, обложках альбомов и динамических цветах Material You / альбома.
* **Оптимизация производительности рендеринга:** устранение тяжелых вычислений теней и нормализация аппаратного ускорения (`hardware layers`), что решает просадки кадров в сложных экранах и при быстром скролле.

### ⚡ 2. Жест добавления в очередь в стиле Spotify (Swipe-to-Queue)
* **Быстрое управление очередью свайпом:** смахните любой трек в списке альбома или плейлиста вправо (или влево в зависимости от настроек), чтобы мгновенно отправить его в текущую очередь воспроизведения.
* **Капсульная динамическая анимация:** подложка жеста плавно выезжает в виде аккуратной капсулы с динамическим цветом из палитры обложки альбома.
* **Тактильный отклик (Haptics):** четкая вибрация при пересечении порога активации жеста и подтверждении добавления.

### 💿 3. Улучшения экрана альбома (Album Detail Screen)
* **Плавающая кнопка воспроизведения (Play FAB):** быстрая кнопка запуска альбома, адаптированная под цветовую гамму релиза.
* **Детальная информация о длительности:** отображение суммарного времени звучания всего альбома, а также длительности каждого отдельного диска (для многодисковых изданий).

### 🏷️ 4. Пакетное редактирование метаданных альбомов (Album Metadata Editor)
* **Полноценный редактор тегов альбома:** редактирование названия альбома, исполнителя альбома (`Album Artist`), жанра, обложки и ReplayGain для всего альбома сразу.
* **Синхронизация с базой данных и треками:** автоматическое обновление всех входящих в альбом треков в медиатеке.

## ✨ Основные возможности (Core Features)

### 🎵 Воспроизведение
* **Media3 ExoPlayer** с интеграцией FFmpeg.
* **Поддержка форматов:** MP3, FLAC, AAC, OGG, WAV, ALAC, OPUS и др.
* **Gapless Playback & Crossfade:** бесшовное переключение и настраиваемые плавные переходы.
* **Редактор очереди воспроизведения:** удобная сортировка, перемешивание и быстрый свайп треков в очередь.

### 📚 Медиатека и поиск
* Сортировка по трекам, альбомам, исполнителям, жанрам и папкам.
* Автоматическая группировка многодисковых изданий.
* Умный поиск по всей музыкальной коллекции.
* Автоматическая загрузка обложек и изображений исполнителей.

### 🎤 Тексты песен
* Синхронизированные построчные тексты (LRC) через LRCLIB API.
* Встроенный просмотр и редактирование текстов.

## 🛠️ Стек технологий

| Компонент | Технология |
|-----------|------------|
| **Язык** | Kotlin 100% |
| **UI** | Jetpack Compose + Material Design 3 |
| **Аудиодвижок** | AndroidX Media3 ExoPlayer |
| **Архитектура** | MVVM + StateFlow / SharedFlow |
| **Dependency Injection** | Hilt |
| **База данных** | Room |
| **Метаданные** | TagLib |
| **Загрузка изображений** | Coil |

## 📱 Системные требования

* **Android 11** (API 30) или новее.
* Рекомендуется от 4-6 ГБ оперативной памяти для комфортной работы с большими библиотеками.

## 🚀 Сборка проекта

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/your-username/PixelPlayer.git
   ```
2. Откройте проект в **Android Studio** (Ladybug 2024.2.1 или новее).
3. Дождитесь синхронизации Gradle и выполните сборку (`Build` → `Make Project`).
4. Запустите приложение на устройстве или эмуляторе с Android 11+.
